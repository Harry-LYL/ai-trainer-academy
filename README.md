## 🎮 交互（App 式 · 非瀑布流）

参照仓库的「首页地图 + 全屏聚焦视图」结构，**首页只有 hero + 图谱 + 模块卡片**，13 个内容板块各自是独立聚焦视图，不再一页到底：

- **首页地图**：hero + 力导向图谱 + 13 张模块卡片（Apple 风格：顶部渐变条 / 图标块 / 编号 / 计数）
- **聚焦视图**：点卡片 / 图谱节点 / 搜索结果进入；顶栏含「← 返回地图」、标题徽章、**‹ › 前后翻页**、搜索、主题
- **快速导航条**：视图顶栏下方 13 个模块 pill，任意跳转，当前高亮
- **键盘**：`/` 全局搜索 · `Esc` 返回/关闭 · `←` `→` 在视图间翻页
- **力导向知识图谱**：44 节点按 8 大知识域配色，拖拽 / 滚轮缩放 / 点击进模块 / 悬停看释义
- **暗/亮主题**：自动记忆
- **两个计算器**：项目排期（量÷人效×人数+质检+容错）、GSB 盈率（(G+S/2)/总数）
- **深链**：`index.html#eval` 等可直接打开对应视图
