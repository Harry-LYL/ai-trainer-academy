## 🎨 复用的 UI（与产品经理学院一致）

- **全屏背景知识图谱 Hero**：训练师 11 流程节点 + 子节点 + 周标签作为沉浸式背景，居中大标题 + 玻璃统计卡（11 核心节点 / 33 检查点 / ∞ 闭环）+ 渐变 CTA + 入口 pills + 键盘提示
- **全流程 Bento 应用**：左侧 11 流程节点 sidebar + 顶部进度节点 + 核心工作/输出物/注意事项三 tab + 关键检查点勾选 + 关联课程笔记
- **每周总结（课程笔记集 W）**：按周总览 / 核心收获 / 按日期浏览 / 释义 / 流程图 / 每周输出，含 trainer 6 周 15 场
- **知识脉络（K）**：8 大知识域卡片 → 领域深页（概念/方法论/课程链接）
- **知识点速查**：61 术语，搜索 + 分类
- **泳道图**：6 角色 × 8 阶段（+ 多模态 pipeline 第二泳道）
- **暗/亮主题 · 演示模式 · 图谱开关 · 键盘快捷键**（Enter 进入 / W 周记 / K 知识脉络 / G 图谱 / P 演示 / M 音乐）
